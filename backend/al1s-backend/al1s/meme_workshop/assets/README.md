# Meme renderer assets

`NotoSansCJKsc-Regular.otf` is the unmodified Noto Sans CJK SC Regular font,
version 2.004, from the official `notofonts/noto-cjk` release tag `Sans2.004`.
Source: https://github.com/notofonts/noto-cjk/tree/Sans2.004/Sans/OTF/SimplifiedChinese
SHA256: `2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`.
The accompanying `OFL.txt` is the original SIL Open Font License 1.1.

The hand used for the petpet effect is the unmodified five-pose transparent sprite
published by https://benisland.neocities.org/petpet/ at
https://benisland.neocities.org/petpet/img/sprite.png (retrieved 2026-10-08).
Stored as petpet-hand.png, 560 x 112 pixels.
SHA256: fedef6b37205236297e8da5ab86b6ee9d67dc92494c831c140a6ad1cc920fdf2.
The generator's main.js supplies the pose geometry; the Python implementation
keeps existing cropping, speed, size, and output-limit contracts. No website
script or gif.js dependency is executed or fetched at runtime.

Provenance: Know Your Meme traces the standard Pet the X hand to the frog-petting
GIF posted by DitzyFlama on 2020-02-18. It explicitly describes the original
frog video's source as unknown; this is not attribution of the original filming.
https://knowyourmeme.com/memes/mmmm-myes-pet-froge
The site publishes these templates directly but no separate hand-image license
was found; gif.js's MIT software license is not treated as an asset license.
The user approved this exact supplied template for the Bot on 2026-10-08.
